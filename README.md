# Ya3dag\_LanguageExtract

Yet another multi-language support feature for applications.





#### What is the purpose of the project?



This project focuses on providing simple support for multi-lingual texts in applications.
Supporting switchable multi-language functionality for applications can be a major challenge.

Having implemented multi-language support for two applications, I am making this work available 

here for others.



The approach used here involves several steps. These are described in detail in the 'Manual How to Do It.pdf' manual.



#### The steps used



* ###### Creating language definitions

Language definitions are created in the code. Specially formatted text strings are used for this purpose.
These language definitions take the following form: "\&tag=string".
Each tag  must be unique. The tag is used in the code for language translation to retrieve the translation.



* ###### Collect language definitions

All language definitions are collected as text in one or more files using the command-line tool ‘**Ya3dag\_LanguageExtract**’. These files must be stored in a separate subdirectory (e.g., named '**Language-Scan**').



* ###### Make translations

Translations are generated by creating a copy of the '**Language-Scan**' directory and the files it contains. The directory is named after a language, e.g., '**German**'. A separate subdirectory is created for each supported language. Of course, the text in the language files still needs to be translated.



* ###### Using language definitions

When the application starts, data is loaded from one of the language subdirectories. To speed up searches, the language definitions are sorted by tag value. This allows the LangStringLookup() function to quickly access the loaded language data.
